# Pedagogue notes — במה מתחילה המילה?

**Goal:** Phonological awareness — identify the **opening consonant** of a pictured/spoken word; map sound → letter without bare phoneme audio.

**Why this bank:** Age-6 first letters must be ear-clear. Prefer מ ל נ ר שׁ ס ז ד ג פּ צ י; ח only when כ/ק never appear. Ban א ע ה כ ק ט ת ב ו and שׂ as starters. Never co-present confuse pairs in one round.

**Scaffolding:** L1 few + far → L2 more → L3 shape-near → L4 six choices. Always sound-safe.

**Feedback:** Wrong never names the wrong letter; replay the whole word. After 3 misses, silent green blink on correct tile.

**Class use:** Warm-up Oct–Dec (and all year). Ask לילך which letters are taught if distractor pool should shrink to taught set later.
